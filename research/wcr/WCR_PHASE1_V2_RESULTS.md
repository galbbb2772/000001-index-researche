# WCR Phase 1 V2 — Winner Crash / 年度横截面迁移结果

> 标的范围：沪深A股  
> 数据快照：2010-01-04 ~ 2026-09-24  
> 数据库：survivorship-safe PIT，含退市股  
> 形成期正式样本：2010–2024  
> 2025→2026 YTD：Forward-only，不参与模型选择  
> 主宇宙：seasoned180（年初前已上市、形成年末仍上市、当年>=180交易日）

## 1. 研究问题

检验命题：

> A股上涨方向可能难以由上一年收益预测，但极端赢家在下一年进入极端输家组的概率是否显著升高？

定义：
- D1：形成年收益最低10%
- D10：形成年收益最高10%
- Next D1：下一年收益最低10%
- Winner Crash 核心统计：P(Next D1 | Prior D10)

本阶段不使用机器学习，不解释原因，只验证横截面事实。

---

## 2. 数据与幸存者偏差修复

PIT 数据包含 5,559 只证券和退市日期。

形成期要求股票在形成年年末仍存在，这是年末排序策略的自然可交易条件。

**结果期不要求股票活到下一年年末。**

结果期规则：
- 下一年年初仍处于上市区间；
- 下一年至少60个交易日，或在下一年发生退市；
- 年中退市股票保留；
- 退市单独标记，避免把并购/私有化退市机械当成“崩盘”。

年度价格收益使用 `bars.pctChg` 逐日复合：

```
AnnualReturn = exp(sum(log(1 + pctChg/100))) - 1
```

因此不是使用“今天还活着的股票列表”反推历史。

---

## 3. 主结果：D10 → D1

主宇宙：
- Formation observations：46,492
- Valid next-year transitions：46,441
- 下一年缺失率：0.11%

随机/全样本 Next-D1 基准：

```
P(Next D1) = 9.18%
```

上一年 D10：

```
P(Next D1 | Prior D10) = 18.40%
Lift = 2.01x
```

另外：

```
P(Next D1 or D2 | Prior D10) = 31.85%
P(Next D10 | Prior D10)      = 10.75%
```

也就是说，上一年的最强10%股票下一年再次进入最强10%的概率基本接近随机，
但掉进最差10%的概率约为随机基准的两倍。

### 年度稳定性

按每个形成年单独比较 D10→D1 与该年的 D1 基准：

- 15/15 个年份：D10→D1 概率高于当年基准；
- 年均超额概率：+9.95 个百分点；
- 年度 bootstrap 95% CI：约 +7.07pp ~ +13.14pp。

这说明结果不是由单一年份驱动。

---

## 4. “最好的几个票”效应更强

| 上一年收益分位 | 样本数 | 次年进D1 | 相对约9.18%基准 | 次年进D1/D2 | 次年收益中位数 |
|---|---:|---:|---:|---:|---:|
| Top 20% | 9,298 | 15.23% | 1.66x | 28.19% | -3.63% |
| Top 10% | 4,653 | 18.38% | 2.00x | 31.81% | -6.08% |
| Top 5% | 2,332 | 22.30% | 2.43x | 35.85% | -9.10% |
| Top 2.5% | 1,169 | 26.43% | 2.88x | 39.26% | -12.80% |
| Top 1% | 471 | 30.57% | 3.33x | 42.89% | -16.81% |

Top 5% 的 D1 超额概率在 15/15 个形成年都为正。

Top 1% 在 14/15 个年份高于该年基准；极小样本年份波动更大。

**核心形态：Winner Crash 是非线性的，主要集中在极端赢家尾部，而不是平滑的线性反转。**

---

## 5. 平均收益为什么会误导

上一年 D10 的下一年：

- 平均收益：+6.76%
- 中位数：**-6.08%**
- 负收益概率：56.56%
- <= -30% 概率：20.94%
- 全样本 <= -30% 基准：14.17%
- 5% trimmed mean：约 +1.25%

全样本下一年：
- 中位数：约 +1.72%
- 5% trimmed mean：约 +7.10%

因此不能简单说：

> “上一年赢家，下一年平均一定亏钱。”

更准确的结论是：

> **上一年极端赢家的次年分布更左偏，典型股票表现更差，进入极端输家区和大跌区的概率显著升高；但少数继续超级上涨的股票使算术平均值保持为正。**

这更接近一个 **Crash Transition Anomaly**，而不是普通 long-short 均值反转。

---

## 6. 上涨 vs 下跌的非对称可预测性

只使用“上一年收益强弱”这一个变量。

### 预测未来最差10%（DOWN）

Pooled AUC：

```
0.558
```

逐年 AUC 平均：

```
0.590
```

### 预测未来最好10%（UP）

用上一年弱势去预测下一年D10：

Pooled AUC：

```
0.498
```

逐年 AUC 平均：

```
0.497
```

逐年配对：

```
Mean(AUC_DOWN - AUC_UP) = +0.093
Bootstrap 95% CI ≈ +0.058 ~ +0.129
```

因此第一阶段数据支持：

> **过去收益对未来“极端输家”的预测含量明显高于对未来“极端赢家”的预测含量。**

但 DOWN AUC 只有约0.56–0.59，属于弱到中等预测力，远不是单因子高精度模型。

## 7. 跨时期稳定性

主宇宙：

| Formation period | D10→D1 | D10→D1/D2 | D10→D10 | AUC DOWN | AUC UP |
|---|---:|---:|---:|---:|---:|
| 2010–2014 | 23.93% | 36.72% | 6.88% | 0.622 | 0.550 |
| 2015–2019 | 14.81% | 26.58% | 15.83% | 0.533 | 0.455 |
| 2020–2024 | 18.06% | 32.84% | 9.41% | 0.539 | 0.503 |

效应在三个子时期都存在，但 2010–2014 最强，近年预测强度有所下降。

---

## 8. 宇宙口径稳健性

P(Next D1 | Prior D10)：

- seasoned180：18.40%
- all120：18.87%
- nonST180：18.32%

对应 lift 均约 2x。

因此结果不是由：
- 新股短上市历史；
- ST 股票；
- 单一股票池过滤方式

单独造成。

---

## 9. 退市不是主要解释

下一年退市率：

- Prior D10：约 0.34%
- Prior D1：约 2.11%

所以 Winner Crash 的 D10→D1 现象**不是因为上一年赢家更容易退市**。

相反，退市风险本身更集中在原本就弱的股票。

短售约束是否解释 Winner Crash，仍属于下一阶段机制假设，当前不能下因果结论。

---

## 10. 2025→2026 YTD Forward：当前反例

截至数据快照 2026-09-24：

上一年（2025）D10：
- 2026 YTD 平均：+9.28%
- 全样本平均：+0.42%
- D10 - All：**+8.85pp**

所以当前 Forward **不支持“赢家马上平均跑输”**。

但是：
- D10 YTD 中位数：约 -12.23%
- 全样本中位数：约 -11.02%
- 2025 Top1% 的 2026 YTD 中位数：约 -18.56%

这再次显示均值受少数超级赢家强烈影响。

2026 尚未完成，因此本段只记录，不用于修改历史规则。

## 11. Phase 1 判定

### 支持的命题

**SUPPORTED：**
上一年极端赢家，下一年进入极端输家尾部的概率显著上升，而且强度随“赢家极端程度”增加。

**SUPPORTED：**
只使用过去收益时，DOWN 的可预测性显著高于 UP。

### 不支持/尚未支持

**NOT SUPPORTED：**
“D10 下一年平均一定亏损。”

**NOT YET TESTED：**
该现象由 A 股做空约束导致。

**NOT YET TESTED：**
该现象可以直接转化为可实施的做空策略。

### 当前最合理的用途

优先研究：

```
Avoidance Alpha
```

即在 Long-only 组合中识别并剔除 Winner-Crash 高风险股票，而不是先假设可以稳定做空。

---

## 12. 下一阶段

Phase 2 应按以下顺序推进：

1. 极端赢家定义敏感性：Top1/2.5/5/10/20%；
2. Formation × Holding：1/3/6/12/24/36M × 1/3/6/12M；
3. 控制 size / industry / ST / IPO / turnover；
4. 检验 Winner Crash 是否只是小盘、题材、彩票股效应；
5. 再加入可融券/不可融券、融资融券状态测试 short-sale constraint；
6. 最后再与 RPC Mania 状态交互；
7. ML 放到上述机制检验之后。

> 当前结论应称为 Winner Crash / Crash Transition anomaly，不应称为已完成的交易策略。
